# Task 3 — Basic Chatbot

PyBuddy is a simple rule-based chatbot that responds to common messages with predefined replies.

## Concepts used
- `if/elif` conditional logic
- Functions and loops
- String processing
- Console input/output

## Run
```powershell
python main.py
```
Run from this directory, or from the project root use `python Task3_Basic_Chatbot/main.py`.

Try: `hello`, `how are you`, `what is your name`, `time`, `help`, and `bye`.
